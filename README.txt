【這次更新】
1. 首頁心情卡片左邊新增「小動物互動區」，小動物會呼吸、會往滑鼠的方向歪頭。
   直接對小動物：
     點一下 → 被戳（縮一下、冒出「！」）
     點兩下 → 大笑（跳跳跳、哈哈哈）
     連點三下 → 怕癢（抖來抖去、嘻嘻哈哈）
     長按 → 抱抱（滿滿的愛心）
   下方按鈕：摸摸頭、戳一下、搔癢、給愛心、講笑話、稱讚它（害羞）、陪我哭、壓力山大、想睡了
   「壓力山大」會有一座山壓下來，小動物被壓扁後再把山推走。
   對話框左邊的表情符號會跟著換（微笑、害羞、被戳、怕癢、愛心、大笑、哭、壓力、想睡…）。
   選今天的心情時，小動物也會跟著反應（開心→大笑、難過→哭、煩躁→壓力山大、好累→想睡）。
   太久沒互動時，小動物偶爾會自言自語。
2. 歡迎語：首頁標題會依時段變成「早安／午安／午後好／晚上好／夜深了，暱稱！」，
   問候句依時段、星期幾隨機出現，旁邊有「換一句」。
3. 心情卡片新增一句加油打氣，可以按「再一句」。筆記頁、抽籤頁左下角的句子也會隨機換。
4. 所有句子都在 messages.js，想加自己的句子直接在對應的清單裡加一行即可：
   greet（時段問候）、weekday（星期）、cheer（加油打氣）、side（側邊小語）、pet（互動台詞）、jokes（笑話）。
   {name} 會換成暱稱，{pet} 會換成小動物名字。

【怎麼更新】
1. 先在 GitHub 按 Code › Download ZIP 備份。
2. Add file › Upload files，把這個資料夾的檔案和 mascots 資料夾一起拖進去（用 Chrome 或 Edge）。
3. Commit changes，等 1～2 分鐘後強制重新整理。
